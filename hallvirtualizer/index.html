2 · Source

Plays whatever arrives at the chosen MOTU input pair. If Chrome only exposes inputs 1–2, route the pair you want to 1–2 in MOTU's CueMix / web app.
A browser can't tap Apple Music directly, so it goes through a free virtual cable: 1) install BlackHole 2ch (existential.audio/blackhole); 2) in Audio MIDI Setup set BlackHole to the same sample rate as this app; 3) in Apple Music / macOS Sound, set the output to BlackHole 2ch (not the MOTU, or you'll hear it dry as well); 4) choose BlackHole here and press Start. Apple Music's own volume slider then acts as the input level.

3 · Room impulse responses

High-pass: linear-phase, 48 dB/oct (8th-order, Linkwitz–Riley shape, −6 dB at the cutoff), 20–400 Hz, 0 = off. Az: 0 = stage, 90 = left, 180 = behind, 270 = right. El: + = up.
Files are sorted by name and assigned like this: one file per channel → ch 1…N (stereo file = response to the left source + response to the right source; mono file = one response used for both); 2×N mono files → consecutive pairs (left-source, right-source); one multichannel file → N mono channels, or 2×N channels using the layout above. Each output = L ∗ hL + R ∗ hR.

4 · Mix

Outputs follow the pair rule: odd numbers (1, 3, 5 …) are left speakers, even numbers (2, 4, 6 …) are right. Convolved channels start at output 3 by default. The front pair gets no convolution, high-pass or delay — only its level and the master volume.

5 · Offline render (no real-time limits)

Uses the selected track from the section 2 list and the current RIRs, gains, mutes and routing. Renders faster than real time, then downloads a 24-bit WAV with one channel per output, ready to play through the MOTU from any multichannel player. Rough size: 16 ch × 5 min ≈ 640 MB.

6 · Hall model → ray-traced directional RIRs

Plan view (stage on the left)
Method: the exact image-source method for the early specular reflections (with full direction of arrival), plus stochastic ray tracing with surface scattering, frequency-dependent absorption and air absorption for everything else. The late part is synthesized as noise shaped per octave band and per direction by the ray-traced energy. Each arrival is panned to the nearest speaker directions, using the Az/El of each channel in section 3, so the output matches your speaker layout (re-run after changing them). It treats the hall as a rectangular box: balconies, the deep raised stage, organ and ceiling coffers are only represented through the scattering coefficient. Expect a plausible "Concertgebouw-like" room, not a measurement of it.
